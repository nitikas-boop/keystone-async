# Infrastructure review: cloud provider

Attendees: Vikram Shah (CTO), Ananya Rao (CEO), Rohit Kulkarni, Divya Nair.

Vikram opened by asking whether Project Atlas should stay on AWS Mumbai, where everything has run since the November standardisation.

Ananya raised data residency. Our banking partners now ask for written confirmation that customer financial data is stored and processed on infrastructure operated in India, and she expects the regulators to tighten this further.

Rohit presented the cost comparison. The India-hosted provider quoted lower monthly costs for the same capacity and charges no cross-region egress fees, which make up a growing share of our AWS bill.

Divya noted that migration would take about six weeks and that the backup jobs would need to be re-pointed.

Vikram decided that Project Atlas will move from AWS to the India-hosted provider, for two reasons: data residency and cost. He will record the decision in the decision log this week.

Action: Rohit to draft the migration plan.
